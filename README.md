# ✈️ Sistema de Gestión de Reservas - Aerolínea

Sistema web integral para la gestión de reservas, venta de tiquetes y paquetes turísticos de una aerolínea nacional.

## Descripción del Proyecto

Plataforma web desarrollada como proyecto integrador de Programación en Ambiente Web I que permite gestionar de manera completa las operaciones comerciales de una aerolínea, incluyendo:

- Registro y gestión de clientes
- Reservas de vuelos nacionales e internacionales
- Compra de tiquetes aéreos
- Adquisición de paquetes turísticos adicionales
- Administración de estados de reservas

- **Frontend:** HTML5, CSS3, JavaScript
- **Framework CSS:** Bootstrap / Flexbox
- **Arquitectura:** MVC (Modelo-Vista-Controlador)
- **Base de Datos:** PostgeSQL
- **Control de Versiones:** Git & GitHub
- **Diseño:** Figma
- **Modelado:** UML

## Funcionalidades Principales

### Perfiles de Usuario

#### Súper Administrador
- Gestión integral de vuelos y destinos
- Administración de paquetes turísticos
- Gestión de clientes y parámetros del sistema

#### Agente de Aerolínea
- Gestión de reservas
- Confirmación de pagos
- Atención de solicitudes

#### Cliente
- Registro en el sistema
- Búsqueda y reserva de vuelos
- Compra de tiquetes
- Adquisición de paquetes turísticos

## Módulos del Sistema

1. **Gestión de Clientes** - CRUD completo
2. **Gestión de Vuelos** - Programación y control
3. **Sistema de Reservas** - Proceso completo de reserva
4. **Venta de Tiquetes** - Gestión de compras
5. **Paquetes Turísticos** - Servicios adicionales
6. **Reportes y Analytics** - Dashboards informativos
7. **Autenticación** - Control de acceso por roles
